## 2. Key Synthesis & Reusable Architecture Patterns

1. **Clean-Room Modular Monolith:**
   We avoid microservices overhead while enforcing strict architectural boundaries (`app/core`, `app/data`, `app/quant`, `app/risk`, `app/portfolio`, `app/agents`, `app/reports`, `app/notifications`).
2. **Provider-Neutral Market Data Layer:**
   Strict abstract interfaces (`MarketDataProvider`) with runtime data validation, market session calendars (IST 09:15-15:30), and deterministic synthetic fallbacks.
3. **Independent Risk Engine as Supreme Authority:**
   No AI agent and no quant scanner can dispatch a recommendation or execute an order without passing the independent `RiskEngine`.
4. **Anti-Lookahead Sequential Backtesting:**
   Sequential bar-by-bar evaluation with realistic statutory Indian transaction costs (STT, NSE turnover, SEBI fee, Stamp Duty, GST) and explicit slippage.
5. **Idempotent Telegram Signal Pipeline:**
   Structured, evidence-backed alerts with Setup DNA (thesis, evidence, invalidation level, risk/reward) and transparent scorecarding.
